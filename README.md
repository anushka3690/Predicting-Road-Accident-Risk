# Road Accident Risk Prediction

## Project objective

Explore a Kaggle Playground Series road-accident risk prediction task through the notebook in this repository. The analysis reads training and test data, prepares a validation split, and develops a prediction workflow.

## Project files and data

- `ntbk.ipynb` - the project notebook and modeling workflow
- `train.csv` and `test.csv` - expected notebook inputs; the CSV files are not included in this repository

## Reproduce the analysis

Add the competition data files in the location expected by the notebook, install its Python dependencies, and run the notebook cells in order. Check the notebook for the exact target definition, feature preparation, validation method, and evaluation metrics.

No leaderboard result or model-performance figure is stated here; use the notebook's recorded evaluation outputs for the experiment details.
